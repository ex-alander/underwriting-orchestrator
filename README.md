# Underwriting Orchestrator - мультиагентная система для обработки кредитных заявок

## Проблема
Много клиентов, много заявок. Их обрабатывать долго, а просто прогонять через LLM ненадежно. Следовательно, не хватает какой-то системы которая сможет делать это быстро и надежно.
## Решение
Мы запускаем 4 агентов, которые будут разбивать процесс обработки заявки на 4 шага. Тот из них, который будет отвечать на проверку заявки по правилам из кредитной политики, будет работать с применением RAG, поэтому при условии достижения достаточного уровня точности мы сможем генерить что-то типа цитат, например, которые докажут, что модель не тупо сгалюционировала ответ, а реально нашла правильный источник информации, прогнала его через чекер и выдала обдуманный аргументированный ответ

## Ограничения
Мы взяли не все кредитные случаи, а еще есть куда расти нашей точности. Зато мы сделали проект который доказыает, что эта проблема может быть решена с помощью мультиагентных систем.
